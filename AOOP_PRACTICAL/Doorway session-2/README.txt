The Five Invariant Doorways — Java programs

Files:
1. Doorway1Demo.java — Public Setters
2. Doorway2Demo.java — Escaping References
3. Doorway3Demo.java — Mutable Collections
4. Doorway4Demo.java — Liar Equality (equals/hashCode)
5. Doorway5Demo.java — Constructor Leaks and Overridable Methods
6. ProtectedBookingDemo.java — All five doorways combined

Requirement: JDK 17 or later.

Run one program:
  javac Doorway1Demo.java
  java Doorway1Demo

Replace Doorway1Demo with the desired filename/class name for the other programs.
Run each program separately. Do not compile all six together because some examples
intentionally use different classes with the same names.
